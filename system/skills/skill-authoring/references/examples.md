# 스킬 예시 — 좋은 description / 나쁜 description

## 나쁨 (긍정 트리거만)
```
description: 차트를 예쁘게 그리는 방법. 태그 - 차트, 그래프, 시각화
```
비슷한 요청 전부를 끌어당긴다. 표를 원하는 요청, 데이터 조회만 원하는 요청까지 발동.

## 좋음 (경계 포함)
```
description: 캔들 차트 렌더 규약. 태그 - 봉차트, 캔들, OHLCV.
  쓰지 말 것 — 라인/막대 차트(chart 컴포넌트 기본), 수치만 묻는 요청(표로 답).
```

## 자유도 예시

- **높음**: "지문 길이·난이도는 대상 학년에 맞춰 판단한다."
- **중간**: "`quiz_group` 으로 렌더하되 문항 수가 많으면 대단원별로 나눈다."
- **낮음**: "`search_library` → `library_extract_structured`(아래 스키마 그대로) → 렌더. 순서 고정."
